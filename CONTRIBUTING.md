# Contributing

Thanks for helping make Addictive Loop more useful.

1. Fork the repository and create a focused branch.
2. Run `npm install`, `npm run typecheck`, and `npm run doctor`.
3. Test the main cast, catch, miss, instant replay, collection, persistence, and purchase flows in Expo Go.
4. Keep reusable mechanics in `src/kit` and theme-specific code in `src/demo`.
5. Open a pull request explaining the player-facing change and include a short screen recording for visual changes.

Please keep dependencies Expo Go compatible, avoid committing generated builds or secrets, and preserve strict TypeScript checks. By contributing, you agree that your work is licensed under the project's MIT license.
